## Library Timings
Aliases: library timings, what time does library open, library hours, when does library close

**For everyone:** The library is open from **8:30 AM to 8:30 PM**, every day it operates.

## Library Facilities
Aliases: what facilities are available, library facilities, library resources, books available

**For everyone:** The library holds over 10,776 physical books and more than 17,393 e-books, with RFID-enabled automated borrowing — so checking books in/out is self-service via the RFID system rather than a manual desk process.

**For freshers:** You'll need your student ID card active before you can borrow — if your library access isn't working yet, check your ID card status first (see the ID Card doc) before assuming it's a library-side issue.
